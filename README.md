# HZCU New Tab

浙大城市学院风格的新标签页浏览器扩展，兼容 Chromium 内核的 Microsoft Edge 与 Google Chrome。

## 功能

- 以新标签页打开 HZCU 轻首页
- 百度、必应、Google 和 Google 学术搜索
- SUN / MOON 外观切换
- 三栏分类与快捷链接管理，支持新增、编辑、删除和上下排序
- 使用浏览器 `storage.sync` 保存设置与链接
- 响应式布局；无需构建步骤或远程脚本

首版分类使用占位入口，真实校内链接可在扩展中自行添加。公开仓库包含扩展源代码；通过扩展设置添加的链接保存在浏览器中，不会写回仓库。

## 在 Chrome 安装

1. 下载或克隆本仓库，并解压 ZIP（如适用）。
2. 在地址栏打开 `chrome://extensions`。
3. 打开右上角「开发者模式」。
4. 选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的项目文件夹。
5. 新建标签页即可使用。

## 在 Microsoft Edge 安装

1. 下载或克隆本仓库，并解压 ZIP（如适用）。
2. 在地址栏打开 `edge://extensions`。
3. 打开左侧「开发人员模式」。
4. 选择「加载解压缩的扩展」，选中包含 `manifest.json` 的项目文件夹。
5. 新建标签页即可使用。

卸载或停用扩展后，浏览器会恢复原来的新标签页。此版本为开发者模式安装包，未提交到官方扩展商店。
