# HZCU-NewTab

浙大城市学院新标签页扩展，为常用校内系统、科研网站和个人快捷入口提供一个统一首页。支持 Chromium 内核的 Microsoft Edge 与 Google Chrome。

- **第一版正式版：1.0**（Manifest V3）
- **适用浏览器：** Microsoft Edge、Google Chrome 桌面版
- **安装包：** 在 GitHub 的 [Releases](https://github.com/DreamDZL/HZCU-NewTab/releases) 下载 `HZCU-NewTab.zip`

## 安装

本扩展以 ZIP 形式分发，使用浏览器的“加载解压缩扩展”功能安装。它没有发布到 Edge 或 Chrome 官方扩展商店。

1. 从 [Releases](https://github.com/DreamDZL/HZCU-NewTab/releases) 下载 `HZCU-NewTab.zip`。
2. 将 ZIP 解压到一个固定文件夹。不要在浏览器中直接打开 ZIP；解压后的文件夹中应直接看到 `manifest.json`。
3. 在 Edge 地址栏打开 `edge://extensions`，或在 Chrome 地址栏打开 `chrome://extensions`。
4. 打开“开发人员模式”（Chrome 中称“开发者模式”）。
5. 点击“加载解压缩的扩展”（Chrome 中称“加载已解压的扩展程序”），选择刚才解压且含有 `manifest.json` 的文件夹。
6. 新建标签页即可看到城院首页。若浏览器询问是否切换新标签页，选择使用此扩展。

更新版本时，下载并解压新版到固定文件夹，在扩展管理页点击“重新加载”；也可以移除旧扩展后重新加载新版文件夹。请保留解压后的文件夹，否则浏览器无法加载扩展。

## 使用

### 搜索与访问网址

- 在搜索框输入关键词并按 Enter，或点击蓝色搜索按钮，即可使用当前选中的搜索引擎搜索。
- 输入完整网址（如 `https://example.com`）并提交时，会直接打开该网址；按钮会根据输入内容切换为访问图标。
- 点击搜索框左侧图标可选择搜索引擎。
- 点击首页分类方块可打开对应站点。网站图标仅用于识别，不会单独触发操作。

### 自定义首页

点击右上角设置按钮，可以管理常用入口：新增、编辑、删除和调整分类或链接顺序；也可以选择一个关注学院、调整页面显示比例、切换明亮/深色/跟随系统主题。页面比例保存在当前浏览器本地；分类、链接和主题等设置使用浏览器同步存储。

设置中的“重置”会恢复本扩展预设的首页、默认代理行为、主题和 100% 页面比例。重置后，教学平台也会按预设走校园 WebVPN。

## 校外访问校内网站

在校外使用时，请确保设备可以连接互联网，然后通过首页对应的校内入口访问：

1. 点击一个校内网站入口。扩展会把 `hzcu.edu.cn` 及其子域名的地址转换为浙大城市学院 WebVPN 地址。
2. 首次访问、登录状态过期或页面跳转到认证页时，按学校页面提示使用学校账号完成 WebVPN 认证。
3. 认证完成后返回原入口继续访问。若仍显示未登录，可在当前标签页重新打开该入口，或从 WebVPN 页面重新认证。

WebVPN 仅提供学校配置的远程访问通道，不会绕过学校账号权限、网站授权或系统维护状态。部分站点可能要求再次登录，且页面速度取决于校外网络、WebVPN 和目标系统状态。

### 代理规则

- `hzcu.edu.cn` 及其子域名默认通过学校 WebVPN 访问。教学平台已设置为默认走代理；重置后也会恢复此设置。
- 外部域名默认直接访问。编辑链接时可以按需要选择是否通过 WebVPN；例如 PTA、浙大开源镜像等公开服务适合直接访问。
- WebVPN 门户及其代理域名不会再次代理，以避免代理循环。
- WebVPN 网关当前使用学校提供的 `http://…webvpn1.hzcu.edu.cn:8118` 入口形式。如果直接把这类地址改为 HTTPS，可能出现 `ERR_SSL_PROTOCOL_ERROR`。请使用扩展生成的地址，并以学校现行 WebVPN 配置为准。

校外访问遇到问题时，可依次尝试：确认 WebVPN 登录状态；从首页重新打开入口；检查学校 WebVPN 是否能正常访问；确认目标系统本身没有维护或权限限制。扩展不会保存校园账号密码，也不能替代学校的身份认证。

## 隐私与权限

- 扩展仅请求浏览器 `storage` 权限，用于保存首页设置；不读取其他网页内容或浏览记录，不加载远程脚本，也不发送后台分析请求。
- 提交搜索时，搜索词会发送给你选择的搜索服务；访问网站时，浏览器会直接或通过 WebVPN 连接目标站点。
- 分类、链接、主题和搜索引擎设置使用浏览器同步存储；页面比例只保存在当前浏览器。请勿在快捷链接中保存密码、会话令牌或带一次性票据的地址。
- 部分学校 WebVPN 代理入口使用 HTTP。请遵守学校网络与账号安全要求，避免在不可信网络中提交敏感信息。

## 开发与本地安装

扩展是静态文件，无需构建或依赖安装。开发者可克隆仓库，然后按照上面的步骤加载项目根目录（其中应直接包含 `manifest.json`）。
